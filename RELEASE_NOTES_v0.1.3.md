# rwif-builder v0.1.3

Feature release adding the first ARWIF toolchain on top of the RWIF container.

## What Changed

- adds the ARWIF v0.1 mini-spec
- adds an ARWIF validator with strict and legacy-compatibility modes
- adds a reference `arwif -> wav` renderer
- adds CLI commands for ARWIF validation and rendering
- documents the container decision to keep ARWIF RWIF-compatible for now

## Scope

This release extends rwif-builder beyond semantic-memory authoring into a first audio-oriented profile while keeping the existing RWIF container and builder behavior intact.
